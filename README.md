# White-Label E-Commerce Platform UI

Современная полнофункциональная платформа электронной коммерции с настраиваемым white-label брендингом, витриной товаров, чекаутом и панелью управления продавца.

Дизайн разработан с помощью **Google Stitch** на базе дизайн-системы **Luminescent Commerce** (Material 3, Tailwind CSS, Plus Jakarta Sans, Inter).

## 📁 Структура проекта

* `index.html` — Интерактивный хаб со всеми экранами и переключателями разрешений/языков
* `catalog_ru.html` / `catalog_en.html` — Витрина каталога с фильтрами, сортировкой и карточками товаров
* `checkout_ru.html` / `checkout_en.html` — Страница оформления заказа с выбором доставки и оплаты
* `admin_ru.html` / `admin_en.html` — Панель управления продавца (дашборд с метриками и заказами)
* `mobile_ru.html` / `mobile_en.html` — Мобильная версия интернет-магазина (390px)
* `ARCHITECTURE.md` — Архитектурный манифест, схема БД и спецификация REST API
* `AGENTS.md` — Правила разработки, кодстайл и соглашения по архитектуре
* `server.js` — Локальный HTTP-сервер для быстрой демонстрации

## 🎨 Дизайн-система (Luminescent Commerce)

* **Primary:** `#006948` (Изумрудный акцент для ключевых действий конверсии)
* **Secondary / Badges:** `#fea619` (Янтарное золото для скидок и рейтингов)
* **Surface:** `#faf8ff` (Чистая основа с легким нейтральным оттенком)
* **Typography:** `Plus Jakarta Sans` (заголовки) + `Inter` (текст и таблицы)
