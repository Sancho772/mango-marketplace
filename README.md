# 🛍️ White-Label E-Commerce Platform

Коммерческая платформа электронной коммерции с модульной white-label архитектурой, витриной товаров, чекаутом и панелью управления продавца.

Дизайн разработан с помощью **Google Stitch** на базе премиальной дизайн-системы **Luminescent Commerce** (Tailwind CSS, Plus Jakarta Sans, Inter, Material Symbols).

---

## 📚 Документация проекта

Вся критически важная информация для разработки находится в следующих файлах:
* **`PROJECT_CONTEXT.md`** — текущий статус проекта, спринты, известные баги и динамический план задач.
* **`ARCHITECTURE.md`** — архитектурные правила, структура проекта, слои данных, схема БД и спецификация REST API.
* **`RULES.md`** — строгие правила написания кода для ИИ-ассистента и разработчиков (минимальные патчи, запрет на моки, стандарты оформления текста и дизайн-токены).
* **`AGENTS.md`** — расширенные стандарты разработки и кодстайл.

> **Перед началом любых работ ИИ-ассистент обязан ознакомиться с этими файлами.**

---

## 🛠 Технологический стек

* **Frontend:** React 18, TypeScript, Vite, Tailwind CSS
* **Дизайн и UI:** Luminescent Commerce tokens, Plus Jakarta Sans, Inter, Material Symbols
* **Управление состоянием:** Zustand / React Context
* **Backend API:** Node.js (Express), REST API
* **База данных:** SQLite (Better-SQLite3)
* **Аналитика и графики:** Recharts

## 📁 Структура проекта

```text
ecommerce-platform/
├── RULES.md              # Строгие правила разработки и стандарты ИИ
├── ARCHITECTURE.md       # Архитектурный манифест, схема БД и REST API
├── PROJECT_CONTEXT.md    # Динамический трекер задач и текущее состояние
├── README.md             # Основная документация проекта
├── server.js             # Локальный HTTP-сервер для быстрой демонстрации
├── index.html            # Интерактивный хаб предпросмотра всех экранов
├── catalog_ru.html       # Витрина каталога с фильтрацией (RU)
├── checkout_ru.html      # Страница оформления заказа и оплата (RU)
├── admin_ru.html         # Дашборд продавца и аналитика (RU)
├── mobile_ru.html        # Мобильная витрина 390px (RU)
└── *_en.html             # Англоязычные версии экранов
```

## 🚀 Как запустить интерактивный предпросмотр

1. Запустите локальный сервер:
   ```bash
   node server.js
   ```
2. Откройте в браузере: **[http://127.0.0.1:3456/](http://127.0.0.1:3456/)**
   В хабе доступно интерактивное переключение макетов, языков (RU / EN) и мобильного/десктопного разрешений.
